## 📖 正文 · CEFR B1

**AI coding assistants move into the daily workflow of software teams**

Artificial intelligence coding assistants have moved from a novelty to an ordinary part of the working day for many software teams. The tools complete half-written functions, generate unit tests, translate code between languages and explain unfamiliar repositories in plain sentences. Two industry surveys published this month suggest that a majority of professional developers now open an assistant at least once per working day, and that the most common uses are writing tests and reading other people's code. Managers report that routine tasks contract, which frees engineers for design work. Yet the evidence also carries a warning: models sometimes produce code that compiles, passes a weak test and still hides a subtle error …

## 🔎 逐句精读

- Artificial intelligence coding assistants have moved from a novelty to an ordinary part of the working day for many software teams.
  - 译：对许多软件团队而言，AI 编程助手已从新鲜玩意变成日常工作里的寻常一员。
- Two industry surveys published this month suggest that a majority of professional developers now open an assistant at least once per working day.
  - 译：本月发布的两份行业调查显示，多数职业开发者现在每个工作日至少会打开一次编程助手。
- Yet the evidence also carries a warning: models sometimes produce code that compiles, passes a weak test and still hides a subtle error.
  - 译：但证据同时也附有警示：模型有时给出的代码能够编译、能通过松散的测试，却仍藏着不易察觉的错误。
- Several companies therefore keep a human review step in their pipeline and exclude security-critical modules from generated changes.
  - 译：因此一些公司仍在流程中保留人工评审环节，并把安全攸关的模块排除在自动生成改动之外。

## 📝 小练习（4 题）

**1.** According to the two surveys, what do most professional developers now do every working day?

- **A.** Open an AI coding assistant at least once.
- **B.** Write all of their tests by hand.
- **C.** Attend a review meeting about generated code.
- **D.** Rotate to a different programming language.

**2.** Why do several companies keep a human review step?

- **A.** Because models refuse to write unit tests.
- **B.** Because generated code can compile, pass a weak test and still hide an error.
- **C.** Because engineers are not allowed to use the tools.
- **D.** Because review is faster than writing code by hand.

**3.** The word contract in the sentence "...contract noticeably, whereas ambiguous work can expand" is closest in meaning to ___.

- **A.** become shorter
- **B.** become more expensive
- **C.** grow larger
- **D.** vanish completely

**4.** Which change is most likely to be excluded from generated code by company policy?

- **A.** A user interface colour change.
- **B.** A documentation typo fix.
- **C.** A modification in security-critical modules.
- **D.** A new unit test for a helper function.


<details>
<summary>✅ 参考答案与解析（点击展开）</summary>

1. **A** — 细节题。B1 正文指出 a majority of professional developers now open an assistant at least…
2. **B** — 因果细节题。原文说明模型有时会产出“能编译、能通过松散测试却仍藏着错误”的代码，因此保留人工评审，B 正确；A、C 与原文相反，D 未提及。
3. **A** — 词义推断题。contract 与 expand 由 whereas 构成对比，expand 指耗时变长，故 contract 指耗时缩短，选 A。
4. **C** — 细节题。原文提到公司把 security-critical modules（安全攸关模块）排除在自动生成改动之外，C 正确；A、B、D 属于低风险或非核心改动。
